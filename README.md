# pdf

A package for [Scaly](https://scaly.io) that writes PDF files: a document of
pages carrying text, rules, filled rectangles and images, with named
destinations and page labels.

It is small on purpose. Text is UTF-8, set in one of two kinds of font:

- the standard fonts every PDF reader brings along — Helvetica, Times and
  Courier, each upright and italic, medium and bold. Nothing is embedded;
  they have the characters of Windows code page 1252 and print `?` for any
  other;
- TrueType fonts the document is given. Such a font is embedded with the
  glyphs the document uses, and the text may be any Unicode the font has.
  `PdfFontFiles` finds the file of a family and style among the fonts of a
  directory.

Either way a program can measure a run before it places it. Images are JPEG
and PNG. The package needs no library.

It places marks where it is told to; it does not break lines or pages. The
PDF backend of [dazzle](https://github.com/rschleitzer/dazzle) is built on
it and does.

## Use

```scaly
package scaly 0.1.0
package pdf 0.1.0

use pdf.Font.PdfFont
use pdf.Document.PdfDocument

var doc PdfDocument()
doc.begin_page(595276, 841890)                  ; A4
let font PdfFont.select("Times", true, false)   ; bold, upright
doc.text(font, 24000, 72000, 100000, "Hello")
doc.line(72000, 110000, 523000, 110000, 500)
doc.end_page()
doc.write(String("hello.pdf"))
```

Lengths are integers in thousandths of a point, and a position is measured
from the top left corner of the page, y downwards. Text is placed at its
baseline.

A font of the system, by its family name:

```scaly
use pdf.FontFiles.PdfFontFiles

var files PdfFontFiles()
files.scan(String("/usr/share/fonts"), 3)       ; three levels down
let path files.find("DejaVu Serif", false, true)   ; italic
let serif doc.add_font(File.read_to_string(path).as_slice())
doc.text(serif, 12000, 72000, 140000, "Ελληνικά, Кириллица, 中文")
```

| | |
|---|---|
| `PdfFont.select` | a standard font by family name, weight and posture |
| `PdfFontFiles.scan`, `find` | the font files of a directory; the file of a family and style |
| `add_font`, `text_width`, `has_character` | take a TrueType file's bytes; measure text in a font; ask whether it has a character |
| `begin_page`, `end_page` | a page of a width and height |
| `set_color`, `text`, `line`, `fill_rectangle` | marks on the open page |
| `add_jpeg`, `add_png`, `image` | take an image file's bytes, place the image |
| `add_destination`, `add_page_label` | a named place; how a reader numbers the pages |
| `clear` | forget the pages and keep the fonts, to set the pages again |
| `finish`, `write` | the bytes of the file; the file |

The file is PDF 1.4 and carries no date and no identifier: the same calls
write the same bytes.

A font must have TrueType outlines; one with PostScript outlines (`OTTO`)
is refused, and of a collection (`.ttc`) the first font is taken. The file
embedded holds the outlines of the glyphs used and keeps every glyph's
number. There is no shaping: a character is its glyph, placed left to right.

A JPEG and a PNG without alpha channel go into the file as they are. A PNG
with an alpha channel is decoded, and its transparency becomes a soft mask;
it is written run-length coded, which is the only compression here. An
interlaced PNG is refused.

## Build and test

Install Scaly and declare the package with where it comes from:

```scaly
package pdf 0.1.0 "github.com/rschleitzer/pdf"
```

`scaly build`, `run` and `test` fetch it with git the first time. (Without
the address the compiler looks for `packages/pdf` in the `packages` directory
of the program that uses it, or of the installation.)

**A published version does not change.** What the default branch here holds
as `packages/pdf/<version>` is published: whoever fetched the version has
exactly those files, and Scaly refuses a version that differs from what it
fetched first. `scaly publish --check`, which the tests run, says so when a
published directory is not what it was. A change to the package goes into a
new version directory beside it.

```sh
tests/run.sh
```

`packages/pdf/0.1.0/pdf/Metrics.scaly` is generated by `tools/metrics.py`
from the Adobe Font Metrics files of the standard fonts in `tools/afm`. The
two fonts the tests embed, `tests/data/tiny*.ttf`, are written by
`tools/tinyfont.py`; their glyphs are rectangles.
